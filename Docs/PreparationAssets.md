# Preparation visual assets

Created with the built-in ImageGen tool. Project copies are in `Assets/Resources/Disaster/`. Original character/arrow sheet supplied by the user is reused as `EarthquakeSheet.png` without altering its pixels. Runtime sprites select regions of that sheet.

Import: original resolution, point filtering, uncompressed, no mipmaps. House art is a single static overhead background; markers and UI are separate Unity objects. Detector states are slices of the transparent sheet.
